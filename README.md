
### AI Integrated ECG Monitoring and Early Cardiac Anomaly Prediction System

CARDIAXCARE is a student-developed biomedical engineering prototype that combines an ECG sensor, Arduino Uno, and a Python-based AI prediction model to demonstrate the concept of early cardiac anomaly detection.

The project acquires ECG signals using the AD8232 ECG sensor, sends the data to a laptop through Arduino serial communication, and processes the ECG values using a Python AI model for prediction.

> This project is an academic prototype developed for learning purposes and is **not intended for clinical diagnosis or medical use.**

---

# Project Overview

Cardiovascular diseases are among the leading causes of death worldwide. Early monitoring of ECG signals can help identify abnormal heart conditions before they become severe.

The goal of CARDIAXCARE is to demonstrate how embedded systems and Artificial Intelligence can work together to analyze ECG data in real time.

The complete workflow is:

```
Patient
   │
   ▼
AD8232 ECG Sensor
   │
   ▼
Arduino Uno
   │
USB Serial Communication
   │
   ▼
Laptop (Python)
   │
   ▼
AI Prediction Model
   │
   ▼
Prediction Result
```

# Project Workflow

1. ECG electrodes are connected to the patient.
2. AD8232 captures the heart's electrical activity.
3. Arduino Uno reads the analog ECG signal.
4. Arduino sends ECG values through Serial Communication.
5. Python reads the serial data.
6. AI model processes the ECG signal.
7. Prediction result is displayed.
